# Tharumini Gamage — Portfolio Starter

A custom React + TypeScript portfolio designed around Tharumini's identity as an AI researcher, data science undergraduate, and practical software builder.

## What makes this concept distinct

- Research-first positioning rather than a generic developer introduction
- Editorial / research-console visual style
- Asymmetric featured-project layout
- Filterable project archive
- Dark and light themes
- Responsive design and reduced-motion accessibility
- No copied layout, copy, or branding from the reference portfolio

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

### Vercel
1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Keep the default Vite settings.
4. Deploy.

### Netlify
1. Push the project to GitHub.
2. Import it into Netlify.
3. Build command: `npm run build`
4. Publish directory: `dist`

## Important customizations before publishing

1. Replace the GitHub avatar with a professional portrait in `src/App.tsx` if preferred.
2. Add the paper, dataset, and repository links for **Golden Hour Divide**.
3. Add the correct repository/demo URL for the **AI Shipping Automation System**.
4. Add a downloadable CV to `public/Tharumini-Gamage-CV.pdf` and create a button linking to it.
5. Add a professional email address to the contact section.
6. Review project descriptions, especially repositories whose README files are still limited.
7. Replace `latest` dependency versions with pinned versions after the first successful install.
